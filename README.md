# power_bi_analyst

Repositório relacionado a formação de Power BI Analyst

## Desafio Módulo 1 - LAB Project - Treinando uma IA de Aprendizagem: Explore o Poder do NotebookLM

Este projeto explora o uso da Inteligência Artificial como ferramenta de aprendizagem ativa na preparação para concursos públicos.

O objetivo é utilizar o NotebookLM não apenas para obter respostas, mas como uma ferramenta de apoio ao estudo, permitindo organizar fontes, comparar informações, produzir resumos, criar perguntas de revisão e identificar pontos que precisam de maior aprofundamento.

SAIBA MAIS: https://github.com/robertapcnog/miniguia-estudos-notebooklm
